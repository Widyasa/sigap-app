# CLAUDE.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues; use `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles mapped to GitHub labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: `CONTEXT-MAP.md` at the repo root points to per-context `CONTEXT.md` files. See `docs/agents/domain.md`.
